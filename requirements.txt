# ---------------------------------------------------------------------------
# Saviland 电商运营台 —— Python 依赖
#
# ★ 本项目**不需要单独建虚拟环境**。
#   它直接复用 RAG/Agent 底座已有的虚拟环境（Python 3.12）：
#
#       %USERPROFILE%\my-agent\.venv-rag\Scripts\python.exe
#
#   原因：底座的 Chroma / LangChain / 智谱 embedding 都装在那个环境里，
#   而本项目要**直接 import 底座的 rag_demo 模块**复用它的混合检索。
#   在 Python 3.14 下 chromadb 没有预编译 wheel，单独建环境会卡在编译上。
#   所以：直接用底座的解释器跑，是本项目最稳的部署方式。
#
#   运行方式：
#       <底座venv>\Scripts\python.exe run.py serve     # 打开 http://127.0.0.1:8501
#       <底座venv>\Scripts\python.exe run.py portfolio
# ---------------------------------------------------------------------------
